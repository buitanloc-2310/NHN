## Lưu ý trước khi chạy production

`migrations/0003_reset_auth_bootstrap.sql` là migration có chủ đích xóa tài khoản, phiên đăng nhập và phân quyền cũ. Nếu D1 production đã có dữ liệu tài khoản cần giữ, hãy sao lưu và kiểm tra trạng thái migrations trước khi chạy `npm run db:migrate`.

Các lệnh production nên chạy tại thư mục này:

```bash
npm install
npm run validate
npm run db:status
npm run db:migrate
npm run deploy
```

Sau deploy kiểm tra:

- `/api/health` phải trả `database_ready: true`.
- `/api/auth/setup-status` phải trả `needs_setup: true` nếu database chưa có tài khoản.
